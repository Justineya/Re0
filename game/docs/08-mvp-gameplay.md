# 前期投入最少的玩法（MVP）

目标：用最少美术、最少系统、最少内容，先做出「这就是 ALO 人生模拟」的手感。

## 一句话

**弗莉莉亚里的猫妖新手：试飞 → 吃饭修装备 → 听真假传闻 → 可选北门外打架或去折桨湾钓鱼；世界按月走新闻。**

不做：九族全地图、公会战、世界树可打、3D、联网、Live2D。

## 必做（最小闭环）

| 模块 | 范围 | 不做 |
| --- | --- | --- |
| 建角 | 固定时代「新生 ALO」、种族先只开 **猫妖**（或九族可选但内容仍只服务弗莉莉亚）、身份：驯兽学徒 / 休闲 | 全时代、全职业树 |
| 地图 | 弗莉莉亚城内 4～6 区 + 北原 + 折桨湾 +（可选）旧渠入口一层 | 司伊鲁班、卡坦、世界树内部 |
| 资源 | HP/MP/STA、Yrd、DUR、饱食 | 复杂元素克制表 |
| 飞行 | 城内限高、STA 消耗、耗尽坠落警告 | 空中连招、3D |
| 经济 | 客栈吃饭、铁匠修理、渔具日租、摊位买一份饲料 | 拍卖行、跨城物流 |
| 情报 | 每条消息带标签：亲眼所见 / NPC告知 / 传闻 | 完整调查树 |
| 战斗 | 一场可跳过的北原遭遇（指令制 1～2 技） | PvP、攻略组、空中剑技全集 |
| NPC | 4 人即可：芦花（客栈）、雀风（试飞）、铁钳（修理）、墨碑（假新闻） | 12 人全上 |
| 世界感 | **月结算一条新闻**（世界树进度停滞 / 物价微调） | 战争沙盘 |
| 表现 | 文字 + 状态面板 + 种族 SVG 占位立绘 | 贴图、动画、音效 |
| 叙事 | 模板句即可；有 API 再挂 LLM，且必须校验补丁 | 纯靠聊天记忆当存档 |

## 玩家 30 分钟应体验到的课

1. 你不是天选者（建角无隐藏血统）。  
2. 飞行要管 STA。  
3. 钱会花在修和吃上。  
4. 传闻可能是假的（墨碑）。  
5. 打架可以不打。  
6. 你去钓鱼，月底仍有服务器新闻。

## 明确砍掉的「看起来酷但吃预算」

- 九族主城旅行  
- 公会创建与战争  
- 世界树可进入层  
- 旧 SAO 深层解密（只留一条传闻）  
- 骑乘宠物完整养成（MVP：最多一只非战斗吉祥物或「未解锁」）  
- 立绘动画 / Live2D / 场景大贴图  

## 成功标准

能存档重开；玩 2～3 个游戏月不崩；朋友说「这像 ALO 的日子」而不是「这像任务列表」。

达标后再加：更多 NPC → 商队/驯兽短线 → 旧渠第二层 → 立绘静帧。

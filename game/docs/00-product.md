# 产品定义 · 《岚羽 Online》

## 一句话

单人文字世界模拟：你扮演羽洲服务器里的一个普通账号；模拟层按规则推进时间与因果；叙事层只负责把合法状态讲成可阅读的现场。

## 核心体验（玩家向）

- 你**不是**被选中的勇者、唯一稀有技能持有者、默认神器持有者。
- 你可以攻略天枢木，也可以一辈子在珀尾津开宠物店。两者都是完整人生。
- 世界有九个妖精种族、有限飞行、工匠经济、公会政治、非副本地下城、旧死局《钢茧》的数据残片。
- 情报分等级：亲眼所见 ≠ 酒馆传闻。系统不剧透。
- 你登出或去钓鱼时，月度结算仍会改物价、改攻略进度、改 NPC 日程。

## 三层架构

```
┌─────────────────────────────────────────┐
│  UI 层（Phase 1：终端/网页面板）          │
│  状态条、地点、行动列表、叙事窗口、立绘槽   │
├─────────────────────────────────────────┤
│  叙事层（LLM，可选；可降级为模板句）        │
│  只描述「模拟层已提交的事实」              │
│  输出必须通过补丁校验器才能写回存档         │
├─────────────────────────────────────────┤
│  模拟层（确定论，权威）                    │
│  种子 + 行动 + 月 tick → 新世界状态        │
│  飞行、耐久、物价、危险度、因果边            │
└─────────────────────────────────────────┘
```

### UI 层职责

展示玩家可见信息、收集意图（移动、交谈、飞行、交易、跳过战斗、等待）。**不**自己发明掉落或 NPC 死亡。Phase 1 为文字面板；Phase 5 才把立绘、地图皮换成视觉壳。

### 模拟层职责

- 持有权威存档（JSON）。
- 解析行动为合法效果：扣精力、改关系、推进日程、掷表（用种子，可复现）。
- 每月 tick：公会、物价、天枢进度、钢茧残片、地区传闻包。
- 执行反光环与反刷子规则（见 `03-systems.md`）。
- 地下城是持久地点，不是每次重置的副本。

### 叙事层职责

把「模拟层事件列表」写成第二人称现场。禁止：

- 赠送未在补丁里声明的物品、技能、血统；
- 让 NPC 为取悦玩家而放弃自己的目标；
- 把传闻写成已证实事实；
- 跳过精力/耐久/货币成本。

LLM 输出形态：`{ "prose": "...", "patch": { ... } }`。校验器对照 schema 与当前状态，非法补丁丢弃并回退到模板叙事。

## IP 立场（设计强制）

本作为**原创 IP**。机制可对照 `alo-prompt/` 考古，客户端、立绘提示词、商店文案、直播标题均不得出现下列词（含谐音商标用法）：

Sword Art Online、SAO、ALO、ALfheim、Kirito、Asuna、RECT、Yggdrasil 作为产品名、桐人、亚丝娜、刀剑神域、阿尔普海姆币 Yrd。

可用的是**民俗种族英译**（Sylph、Cait Sith 等）作为内部 `codename`，玩家界面默认显示中文族名（翠风族、珀尾族……）。

旧死局只称 **《钢茧》** 或内部码 `steel_cocoon`。运营方称 **澄空织造**。世界树地理体称 **天枢木**。

## 平台与范围

| 阶段 | 交付 |
| --- | --- |
| Phase 0（本目录） | 圣经 + 起始 JSON + 立绘 ID 约定 |
| Phase 1 | 单机文本客户端、存档、无 LLM 也可玩、LLM 补丁校验 |
| Phase 2 | 月 tick 全量、经济、公会最小 |
| Phase 3 | 多脊骨事件图、因果边 |
| Phase 4 | 钢茧异常、天枢远程新闻 |
| Phase 5 | 视觉壳：立绘、简易地图、音效 |

**不做：** 实时 MMO 联网、用户生成付费抽卡、3D 先行。

## 模拟风格（创建角色时可选，只调叙事温度与事件密度）

1. 极度日常（低战争、低异常，默认）
2. 经典冒险（野外与地下城权重↑）
3. 公会政治
4. 钢茧调查（异常可见度↑，仍无主角光环）
5. 混合

风格**不**改变种族数值上限，只改变事件表权重与反热闹协议的阈值。

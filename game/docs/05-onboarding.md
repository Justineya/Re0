# 新手讲解 · 完整节拍与 UI 文案

目标：2–4 个游戏小时内教会——你不是天选者、飞行会摔、钱会没、传闻会假、战斗可跳、世界不等你。  
允许随时「跳过战斗」；允许中途去钓鱼，模拟层照走。

**语气：** 登录器像运营公告；NPC 像忙人；系统提示像 HUD，不说教世界观论文。

---

## Beat 0 · 启动画面（UI）

**标题：**  
`ALfheim Online　九族世界模拟`

**副标题：**  
`你不是被选中的人。你只是其中一个有翅膀的人。`

**按钮：** `创建角色`　`读取存档`　`设定`

不要在此解释旧SAO或世界树真相。

---

## Beat 1 · 角色创建（UI 文案）

页眉：`选择你的起点　·　提交后世界不会为你重排。`

### 1.1 时代 `era`

帮助文本：`时代决定开局新闻与物价，不决定你的命运。`

1. 旧ALO事件前夜  
2. 新生ALO开服初期  
3. 种族战争激化期  
4. 世界树攻略停滞期（**推荐**）  
5. 旧SAO残片扩散期  
6. 公会联合统治期  
7. 自定义（高级）

推荐旁注：`停滞期适合先学生活。攻略仍在远处失败。`

### 1.2 种族 `race`

九族列表用中文名 + 一行特长。猫妖旁注：`驯兽 / 短剑 / 骑兽 / 情报很快——真假都快。`

自定义外观入口：`外观可调，特性仍来自九族之一。`

### 1.3 身份 `origin`

1. 新手独行  
2. 工匠学徒  
3. 商人  
4. 情报贩子  
5. 公会新人  
6. 攻略组候补（**旁注：** 只是想当，没有内定席）  
7. 佣兵  
8. 驯兽师学徒  
9. 休闲玩家  
10. 旧SAO相关者（**仅背景，无额外能力**）  
11. 自定义

### 1.4 其余字段

- 姓名、外观年龄、性别  
- 出生地：首都 / 弗莉莉亚（推荐） / 其他中立城  
- 现实侧：`只影响可玩时段的叙事，不给数值外挂`  
- 初始技能：可由身份生成  
- 元素亲和：九元素 / 均衡 / 随机  
- 性格三词、一句话人生目标  
- 模拟风格：日常 / 冒险 / 政治 / 旧SAO调查 / 混合  

**提交按钮：** `展开第一对翅膀`

**提交失败校验：** 未选种族、未填名。

## Beat 2 · 第一次登录（过场 + HUD）

黑场运营字（可跳过）：

```
RECT Progressive　·　ALO 登录协议
校准翅膀神经映射……
精力池：已连接。落地缓冲：已连接。
注意：空中精力耗尽将强制降落。
```

落地：弗莉莉亚试飞场边缘，晨，天气 clear。

**HUD 初值（独行新手例）：**

```
岚历 7年·芽风月　晨
地点　弗莉莉亚 · 试飞场
HP 100　MP 80　STA 100　Yrd 80
危险度 0　情报权限：本地
```

**系统句（eyewitness）：**  
你的靴子踩在木桩上。风从弗莉莉亚北原来，带着草腥。北面，世界树只是一条淡青的柱影——很远。没有人鼓掌。

**雀风（未点名时显示「飞行教官」）：**  
「新翅膀？看牌子。STA 掉到两成就给我落地。摔伤的修理费自理，诊所在镜川那儿。」

牌子 UI：

```
试飞场规则
· 城内限高 40 尺
· 精力 ≤20% 必须降落
· 雷暴关闭
· 教官不负责你的人生目标
```

**可选目标插入（不强制）：**  
`[ ] 完成一次往返低空巡航`  
`[ ] 去草尾客栈登记床位`  
`[ ] 无视教程，走出北门` ← 合法

## Beat 3 · 安全区步行（草廊→弗莉莉亚市集）

移动选项：`跟雀风走到客栈` / `自己沿飞廊走` / `立刻试飞`。

芦花：  
「欢迎来津。床 8 Yrd一晚，包一口粥。渔具 3 铢日租。世界树？啊，你是说世界树。板报在弗莉莉亚市集。别全信。」

**系统：** 你登记了床位。这不绑定任何主线。

步行教学：危险度条保持 0。可打开地图：北驿门、弗莉莉亚市集、驯兽街、南苔门。

---

## Beat 4 · 第一次飞行 + 精力警告

雀风任务（可拒绝）：桩到北驿门顶来回，限高。

**操作提示：**  
`[巡航]` 耗 STA 约 1.2/秒　`[悬停]` 更费　`[降落]`

飞到 1/3 时强制插入（若玩家 STA 仍高，则在回程插入模拟侧风，多扣 15 STA）：

```
⚠ 精力 20%
强制降落协议将在 0% 启动。
城内摔伤减半，但 DUR 照扣。
```

若玩家无视飞到 0：坠落伤 + 雀风骂人 + 铁钳报价修理。

雀风：  
「看吧。翅膀不是无限外挂。去吃饭，STA 空着回得慢。」

**成功：** 飞行熟练度 + 微量（第一次不递减）。

## Beat 5 · 经济第一课（修理 / 食物）

铁钳（若摔过则语气更差）：  
「剑刃卷了。修一次 12 铢，学徒价 9 铢但要等。DUR 到 0 是废铁，不是情怀。」

芦花或摊贩：  
「干粮 4 铢，热汤 6。饱食掉了，精力回得很丑。别省这口。」

**UI 课：** 资产面板展开：Yrd、DUR、SAT。  
**失败演示（可选）：** 不修去砍弗莉莉亚北原风鼠，武器提前报废。

阿穗可插入一句（驯兽学徒身份则提前）：  
「兽也要吃。你不吃可以硬撑，它们会咬你。」

## Beat 6 · 传闻 vs 亲眼所见

弗莉莉亚市集。墨碑喊：  
「独家！云环已破，枢卫倒下！资料 15 铢！」

铃小满在旁边唱歌，歌词是「三层，还是三层」。

**系统若玩家买墨碑情报：** 条目写入日志，标签 **传闻**，来源 墨碑。  
**系统若玩家询问刚从北方回来的苔须：** 苔须：`「营地还在。有人死了游戏里那种。没破。」` 标签 **NPC告知**。  
**系统若玩家从未离开津：** 世界树仍只是柱影，**亲眼所见**仅限「看见远影」，不包含攻略进度。

芦花课后（可错过）：  
「在津，消息比饲料跑得快。真的少。」

## Beat 7 · 第一次可选战斗（可跳过）

北门外弗莉莉亚北原，危险度 1。风鼠或野羊。灰芽可能卡在折翼碑（若玩家去北门）。

选项：

```
[交战] 短剑或法术　消耗 DUR / STA
[驱赶] 检定，失败则仍进入交战
[绕开] 合法。灰芽自己想办法
[帮助灰芽但不战斗] 给 8 铢修剑或护送回门
```

战斗 UI 必须有 `[逃跑]`（安全区方向，耗 STA）。

结束无论输赢：  
「这不是试炼场。没人给你勋章。」

若救灰芽：写因果边 `save_huiya`，**不**弹成就「命运之子」。

## Beat 8 · 世界继续：去钓鱼

任意时刻，草廊：`[租渔具]` `[走到折桨湾]` `[钓鱼 1 / 4 / 8 小时]`。

钓鱼中 UI 每小时刷一行**远处摘要**（地区过滤）：

```
（你在折桨湾）
· 弗莉莉亚市集饲料价格微调 −1%
· 试飞场：两名新手打架被罚款（传闻）
· 北线驿站：攻略营地申请加急合金（传闻）
```

若钓 8 小时：暮色、饱食下降、床位可能被占（若没付钱）。NPC 日程推进：阿穗收摊、井底出摊。

**系统收束句（仅此一次，避免说教）：**  
你不在场的时候，阿尔普海姆没有暂停。

之后不再重复这句，靠 HUD 时间走字。

## 跳过与失败

- 跳过教程按钮：保留 HUD 警告与危险度，不强制 NPC 对话。  
- 创建身份「休闲」：Beat 7 权重降低，阿穗权重升高。  
- 「攻略组候补」：仍走同样飞行/经济课，只在板报多一条招人传闻，**没有传送。**  
- 玩家死在弗莉莉亚北原：诊所醒来，Yrd 损失，雀风：「欢迎回来，还是那块牌子。」

## 教程完成条件（隐藏，用于 UI 勾选）

不弹「章节完成」大窗。日志可记：

- 理解 STA 警告  
- 付过一次食物或修理  
- 至少一条传闻标签的情报  
- 知道战斗可跳  

全部可选。完成度 0 也可以存档。

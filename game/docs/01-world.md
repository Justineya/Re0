# 世界观圣经 · 岚羽界 / 羽洲

玩家界面世界名：**岚羽 Online**。内部码：`galeplume`。大陆名：**羽洲**。历法：**岚历**。运营方（虚构）：**澄空织造**。

本文是设计权威。数字与地名以 `game/data/*.json` 为准，文档解释其意义。

---

## 1. 宇宙论（玩家可知 vs 设计层）

### 1.1 玩家开局可见的宇宙

羽洲是一张被大气海托住的大陆。大陆中央偏北升起一座穿透云层的巨木——**天枢木**。九族相信翅膀是「被天枢木允许的借力」，不是神恩。太阳与双月（**银盘**、**墨盘**）按岚历运行；墨盘朔望时，部分幻系与暗系法术效率 +5%～+12%，飞行高空风切更乱。

没有创世神话被系统证实。各主城神殿贩卖互相矛盾的起源故事，全部标为情报等级 **传闻**。

### 1.2 设计层宇宙（勿在新手期剧透）

岚羽是澄空织造运营的 VR 世界。其底层协议栈里嵌着更早的死局项目 **《钢茧》** 的数据残片（意识快照、错误碰撞体、被禁用的伤害公式）。天枢木顶端同时是叙事目标与权限沙箱：旧运营曾把「第一人登顶奖励」写进营销，又在一次权限事故后部分重置顶层。

第五层（协议底层）不是玩家地图，是模拟器用来放异常源与关服开关的命名空间。

### 1.3 五界层（结构，不是楼层副本）

层级描述的是**准入与风险**，同一地理坐标可以同时属于低层日常与高层异常（例如珀尾津下水道某段夜里会切到钢茧噪声）。

| 层 | 名称 | 谁生活在这里 | 准入 |
| --- | --- | --- | --- |
| L1 | 日常层 | 新手、工匠、渔民、摊主 | 开局即在 |
| L2 | 文明层 | 议会、公会大厅、商会、情报行 | 声望/介绍信/种族关系 |
| L3 | 冒险层 | 高级原野、持久地下城、争夺带 | 装备、飞行、队伍 |
| L4 | 天枢与残片层 | 天枢外围迷宫、守护构装领域、封锁管理区 | 攻略组资格或异常卷入 |
| L5 | 协议层 | 管理员空间、世界间通道、钢茧核 | 剧情/事故，不可作为日常地图刷 |

L1 的价值判断：一个熟练锻造师 > 一个只会低阶火球的法师。

## 2. 天枢木（世界树类比，原创地理）

- **名称：** 天枢木（内部 `arbor_axis`）
- **位置：** 羽洲几何中心偏北，根系侵入三族边境的**枢根荒原**。
- **可见高度：** 从珀尾津晴天可看到淡青色柱影，距离仍需数日巡航或商队。
- **攻略定位：** 服务器级长期战，不是个人主线。顶端「第一人奖励」为**运营未证实传说**（情报等级：传闻）。
- **守护构装：** **枢卫**（非骑士商标）。多相位、高伤害、会针对飞行编队。
- **现状（默认开局种子 `era_raid_stalled`）：** 攻略停滞于「云环三层」；本月无突破；物资消耗让熔冠城火药与炉环城合金涨价。

玩家可以从未到过天枢木。新闻以**地区过滤**到达珀尾津：多为过期、夸张、商会抹黑对手的版本。

## 3. 历史阶段（影响当前格局，不是过场）

| 阶段码 | 玩家创建可选名 | 要点 |
| --- | --- | --- |
| `era_launch` | 岚羽正式运营 | 九族可选，飞行公开，天枢木被写成终局广告 |
| `era_tree_stall` | 天枢攻略停滞 | 枢卫过强；种族领地与公会生态成形；天枢变为象征 |
| `era_cocoon_shock` | 钢茧冲击 | 外部死局阴影；部分数据与异常意识漏入；官方与玩家共同遮掩 |
| `era_old_gale` | 旧岚羽权限事故 | 顶层权限被滥用；外部势力与玩家介入；事件「解决」但真相未公开 |
| `era_reopen` | 新生岚羽 | 顶层部分重置；残片、异常迷宫、异常枢卫仍在深层 |
| `era_now` | 当前时代（默认） | 恩怨、公会兴衰、钢茧传闻、地下经济全部在线 |
| `era_race_war` | 种族战争激化 | 特定走廊全面 PvP |
| `era_guild_hegemony` | 公会联合统治 | 自由都市法令被商会改写 |
| `era_fragment_bloom` | 残片扩散 | 异常天气与错误区更常见 |
| `era_custom` | 自定义 | 设计用，需手写修正包 |

历史**不会停止**：登录后仍会发生战争、公会解散、物价、野怪迁徙、地下城改道、残片异动。玩家不参与，世界照样 tick。

## 4. 羽洲地理总览（九族家园）

羽洲不是圆形主题公园。商路要走风廊、河运、地下轨道；种族主城之间默认敌意或冷淡，中立贸易点才是新手该去的地方。

### 4.1 种族主城

| 族 | 主城 | 地貌 | 对珀尾津的距离感 |
| --- | --- | --- | --- |
| 翠风族 Sylph | **风廊城**（翠丘） | 翠绿丘陵、常年上升气流 | 西北，熟练巡航约 14 飞行时 |
| 赤焰族 Salamander | **熔冠城** | 火山、赤岩、热风 | 西南，商队 11 日，飞行热风危险 |
| 澄澜族 Undine | **镜泽城** | 湖滨、湿地、栈桥 | 东，水运 6 日 |
| 磐根族 Gnome | **石心城** | 地下城邦、岩脉矿 | 北，地下轨道 4 日（表面荒原高危） |
| 珀尾族 Cait Sith | **珀尾京** | 草原—森林交界的环形市 | 南，陆路 2 日；**珀尾津是其卫星贸易镇** |
| 铃歌族 Pooka | **弦都** | 平原文化都市、露天剧场 | 东南，驿路 8 日 |
| 穴影族 Imp | **夜井城** | 洞窟多层都市 | 东北地下，需通行证 |
| 雾纹族 Spriggan | **残碑城** | 遗迹密布的雾原 | 正北雾带，导航易偏 |
| 金砧族 Leprechaun | **炉环城** | 工房环城、烟与蒸汽 | 西，运河+铁路 5 日 |

**玩家自由都市（跨族）：** **三羽港**（南岸）、**律衡**（旧战场上的中立法城，文明层）。珀尾津法律上是珀尾京册封的**开埠津**，实际由商会与卫队共治，九族混居。

### 4.2 天枢周边

- **枢根荒原：** 中危—高危，根系拱起地面，飞行有乱流。
- **云环外围迷宫：** 持久地下城（树体廊道），非副本。
- **禁飞结界：** L4 部分高度强制滑翔或禁止振翅。

## 5. 起始地区：芦风原—苔影林交界（完整）

开局默认落点：**珀尾津**（`loc_amber_crossing`）。选择其他出生地只改关系修正，教程仍建议把「第一座城」做成津内安全区。

### 5.1 珀尾津（安全区，危险度 0）

草原尽头、苔影林北缘、芦水与风廊旧驿路交汇。人口约 1.8 万（含大量过客）。建筑：木廊、兽栏、低空停机桩、三层以内的飞廊。城徽是一枚琥珀色兽尾绕着麦穗。

**分区：**

| 分区 ID | 名称 | 功能 |
| --- | --- | --- |
| `amber_gate_north` | 北驿门 | 通往芦风原；卫队盘查犯罪者 |
| `reed_market` | 芦市 | 摊位、拍卖行分所、修理、食物 |
| `grass_inn` | 草廊客栈 | 床、传闻、渔具出租 |
| `wing_yard` | 试飞场 | 新手飞行教官、精力警告牌 |
| `tamer_row` | 驯兽街 | 珀掌柜阿穗的店、饲料、兽医 |
| `clinic_mirror` | 镜川诊所 | 治疗、异常伤口会被记录 |
| `forge_clamp` | 钳炉工房 | 修理、劣质铁、学徒床位 |
| `night_well_alley` | 夜井巷 | 入夜后情报与灰市（仍算城内，PvP 禁止，但诈骗不禁止） |
| `watch_keep` | 石岸卫所 | 犯罪者、赏金告示 |
| `south_moss_gate` | 南苔门 | 通往苔影林边缘；傍晚关闭半扇 |

**法令：** 城内禁止直接攻击。犯罪者进门会被卫队与玩家猎人盯梢。飞行高度城内限制 **40 尺**（低空），违者罚款 20–80 岚铢。

### 5.2 芦风原（低危险，危险度 1）

珀尾津北。浅丘、芦苇、野羊与风鼠。主动怪少，偶有过路佣兵摩擦（PvP 偶发，掉落风险低）。适合第一次出城、采集饲草、钓鱼点 **断桨湾**（芦水曲）。

**地标：** 折翼碑（纪念一次热风事故）、三座停机桩、商队宿营圈。

### 5.3 苔影林边缘（低—中危险，危险度 1–2）

南门外。树冠可走，地面潮湿。珀尾族骑兽小径与翠风侦察标记重叠。日间危险度 1，雾夜 2。林深处（非开局）有持久地下城入口。

### 5.4 旧渠地下道（非副本地下城，危险度 2）

`loc_old_canal`。珀尾津历代扩建留下的排水渠、仓储与倒塌的驿路隧道。怪物刷新与材料随**被走通的次数**衰减，不会每日 0 点完整重置。公会可争夺「渠口控制」但城内段仍归卫队。

深层某段（设计：玩家调查后才解锁坐标）会在钢茧噪声夜间出现 **错误门**——墙面循环播放已删除的登录 UI。

### 5.5 气候（本地区）

温带草原。春多芽风，秋多金风。苔影林带来晨雾。雷暴时试飞场关闭。元素潮汐每月约 0–2 次，优先影响夜间巷与旧渠。

## 6. 经济

### 6.1 货币

- **名称：** 岚铢  
- **代码：** `LAN`  
- **辅币：** 羽厘（100 羽厘 = 1 岚铢），UI 可只显示岚铢小数。  
- **不要**使用 Yrd 或任何商标币名。

各地物价指数（相对珀尾津芦市 = 1.00）：

| 地点 | 指数 | 备注 |
| --- | --- | --- |
| 珀尾津 | 1.00 | 饲料、修理便宜；合金贵 |
| 炉环城 | 0.85 工业品 / 1.20 食物 | 工族倾销武器 |
| 熔冠城 | 1.15 | 战争溢价 |
| 镜泽城 | 1.10 药品便宜 | 治愈材料产地 |
| 天枢营地 | 1.80+ | 只有攻略后勤价 |

### 6.2 收入与成本

收入：采集、任务、生产、贸易、情报、雇佣、房产租金。  
成本：食物、修理、饲料、公会维护、飞行药剂、床位、罚款。  
**没有**无限刷钱。重复低危采集的收益与熟练度在第 8 次后急剧递减（见系统）。

新手建议储备：修理基金 30 LAN、三日食物 12 LAN、一次紧急降落药 25 LAN。

### 6.3 信息也是商品

情报行卖的是**带等级标签**的文本，售价随过期加速贬值。伪造情报是灰市支柱之一。

## 7. 情报等级（强制）

| 码 | 中文 | 含义 | UI |
| --- | --- | --- | --- |
| `eyewitness` | 亲眼所见 | 模拟层已写入事实 | 实线 |
| `npc_told` | NPC 告知 | 该 NPC 相信如此；可能错 | 标注来源名 |
| `rumor` | 传闻 | 酒馆/歌谣/论坛 | 虚线 + 不可当作任务完成条件 |
| `inference` | 推测 | 玩家或系统根据已知做的推理 | 明确「推测」 |
| `unknown` | 未知 | 无数据 | 留空，禁止 LLM 填 |

世界新闻按**地区、公会频道、职业**过滤。珀尾津新手不会自动获得天枢内部会议记录。

## 8. 危险度

由野怪、PvP、异常、天枢影响、公会控制合成，写入地点字段 `danger`（0–4）。

| 级 | 名称 | 规则摘要 |
| --- | --- | --- |
| 0 | 安全区 | 禁 PvP；低环境伤害；适合生产睡眠 |
| 1 | 低危 | 少量主动怪；偶发 PvP；掉落轻 |
| 2 | 中危 | 中强野怪；PvP 开放；资源密；耐久消耗明显 |
| 3 | 高危 | 强怪、频繁 PvP、公会争夺、部分禁飞 |
| 4 | 极危 | 天枢上层、钢茧错误区；面向顶尖或军团 |

珀尾津 0；芦风原 1；苔影林日 1 / 雾夜 2；旧渠主段 2；错误门深层 4。

## 9. 天气

天气码影响飞行系数、视野、元素、野怪攻击性。

| 码 | 效果摘要 |
| --- | --- |
| `clear` | 飞行 1.00，视野满 |
| `wind` | 巡航耗能 ×0.92（顺）或 ×1.15（逆）；随机切向 |
| `rain` | 火系效率 ×0.85；弓类惩罚；滑行落地易摔 |
| `fog` | 视野短；幻系 +；导航检定 |
| `snow` | 低温；高空额外耗能 |
| `storm` | 试飞场关闭；空中每 10 秒坠落检定 |
| `tide_element` | 某元素 ±15%；旧渠噪声 + |
| `anomaly` | 钢茧侵蚀天气；死亡惩罚表可能被替换为异常表 |

珀尾津开局 70% `clear` / `wind`，10% `fog`（晨），雷暴季节性。

## 10. 时间

- **岚历年：** 开局默认岚历 7 年芽风月（可随时代码改）。  
- **一日：** 24 时辰，UI 可用「晨/午/暮/夜」。  
- **月 tick：** 游戏月结束时跑 `03-systems.md` 月结算。Phase 1 可用「休息到月底」压缩。  
- **世界不暂停：** 玩家钓鱼 4 小时，模拟层推进 4 小时：NPC 走日程、商队移动、远程攻略骰子仍掷。

### 十二月名

芽风、花风、雨风、炎风、金风、雾风、霜风、雪风、蛰风、醒风、祭风、枢风。

枢风月民间会办「望枢节」：放纸翼，不等于攻略日。反热闹协议禁止每月都世界树暴走。

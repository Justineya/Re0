# Phase 1 可玩客户端（下一步）

Phase 0 是圣经与 JSON。Phase 1 做出**单机文本客户端**：无图也能玩完教程与弗莉莉亚日常。LLM 可选。

## 范围

- 读 `game/data/*.json`，不把九族写死在提示词里。  
- 存档：`saves/{slot}.json`（种子、时间、地点、资源、关系边、情报日志、portrait 字段）。  
- 面板：状态、地点行动、人物、背包、日志（带情报等级）、立绘槽（SVG 占位）。  
- 行动：移动、交谈、飞行模式、修理/吃、钓鱼等待、可选战斗、跳过。  
- 时间：行动耗时 → 推进 NPC 日程；提供「等到暮/夜/月末」。  
- 月 tick：最小集（物价、一条地区传闻、灰芽因果权重）。

## 不做（Phase 1）

全阿尔普海姆无缝大地图、实时多人、完整世界树战斗、图像生成管线自动化、3D。

## LLM 补丁校验

若启用叙事模型：

1. 模拟层先算合法结果（骰子用存档种子）。  
2. 模型只写 `prose` + 声明式 `patch`（不得新增物品 id）。  
3. 校验器：schema、资源不为负、地点可达、情报等级不得升级成 eyewitness 除非模拟层同意。  
4. 失败：丢补丁，用模板句 + 模拟层结果。

无 LLM：完全模板叙事，仍然可玩。

## 建议技术

Python 或 TypeScript CLI / 本地网页。确定论核心与 UI 分开。测试：用固定种子跑完 `onboarding-beats.json`，断言 STA 警告触发、钓鱼推进时间、救灰芽写边。

## 验收

- 创建猫妖休闲角色 → 走完飞行警告与经济课 → 可跳过北门战斗去钓鱼 → 存盘读盘后 NPC 不在错误时段出现。  
- 文案扫描：零商标禁用词。

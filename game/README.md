# ALfheim Online · 九族世界模拟（ALO）

> Phase 0 内容圣经。可玩文本客户端是 **Phase 1**。本目录是世界、规则、故事脊骨、新手脚本、立绘管线与起始 JSON。

## 这是什么

《ALfheim Online》**单人文字世界模拟**（确定论模拟 + 可选 LLM 叙事）。玩家不是天选者，只是阿尔普海姆里一个有翅膀的普通账号。世界在登录前已运转很久；你去钓鱼时，世界树攻略组仍可能失败。

本作是**刀剑神域 / ALO 同人向私用设定**：地名、九族、世界树、旧 SAO 残片、RECT、Yrd 直接使用原作称呼。勿用于商业上架或公开收费联机。

机制来源：抖音「哭猫」ALO 世界模拟器提示词（整理见 `alo-prompt/`）。客户端读 `game/data/*.json`，不要把整篇提示词当存档。
